# Смена на ПВЗ

Казуальный симулятор пункта выдачи заказов для Яндекс Игр. React + TypeScript + Vite.

## Запуск

```bash
npm install
npm run dev      # разработка, http://localhost:5173
npm run build    # сборка в папку dist/
```

## Где что лежит

- `src/game/engine.ts` — вся логика и баланс (цифры наверху файла). React тут не используется.
- `src/game/data.ts` — персонажи (внешность), реплики, ситуации с вариантами ответа. Дописывай контент сюда.
- `src/game/events.ts` — события смены (завал, свет, проверка, кот, час пик).
- `src/game/districts.ts` — сеть пунктов: районы, их цены и особенности, звания.
- `src/game/tasks.ts` — задания на смену и награды за них.
- `src/ui/Avatar.tsx` — рисованные персонажи с эмоциями.
- `src/ui/sfx.ts` — звуки, синтезируются в браузере без файлов.
- `src/platform/yandex.ts` — связь с Яндекс Играми: SDK, разметка геймплея, реклама, облачные сохранения.
- `src/platform/vk.ts` — то же для VK Games (ВКонтакте и Одноклассники) через VK Bridge. Нужный файл подставляется при сборке вместо `@platform`; вне площадки оба работают на заглушках.
- `src/ui/FitToScreen.tsx` — вписывает смену в экран без прокрутки.
- `src/fonts.ts` — шрифты внутри игры (внешние сайты на Яндекс Играх заблокированы).
- `src/App.tsx` — экраны: меню, смена, отчёт, улучшения.
- `src/styles.css` — оформление.

## Как выложить на Яндекс Игры

1. `npm run build` — появится папка `dist`.
2. Упакуй в zip **содержимое** `dist` (`index.html` должен лежать в корне архива), имя латиницей.
3. Загрузи архив в черновик и включи «Облачные сохранения».
4. Проверка: открой игру из Консоли с debug-панелью или допиши `?debug-mode=16` к адресу — в углу должно быть `IT`.

SDK подключается в `index.html` строкой `<script src="/sdk.js"></script>`: на сервере Яндекса файл есть, локально его нет, и игра работает на заглушках.

## Как выложить в VK Games (ВКонтакте + Одноклассники)

1. На dev.vk.com создай мини-приложение-игру и впиши его ID в `vk-hosting-config.json` (поле `app_id`).
2. `npm run deploy:vk` — соберёт `dist-vk` и зальёт на хостинг VK. При первом запуске утилита попросит авторизоваться по ссылке.
3. В настройках приложения подключи монетизацию (кабинет выплат cashout.vk.ru, нужна самозанятость или ИП), в «Других платформах» привяжи OK ID и отправь на модерацию.

Локально VK-версию можно запустить так: `npm run dev:vk`.

## Своя версия для телефона

`npm run build:mobile` собирает игру в один файл `dist-mobile/index.html` — без Яндекса и VK, работает без интернета. Реклама там заглушка, есть вибрация и кнопка «во весь экран».

## Android-приложение (APK)

Игра обёрнута в Android-приложение через Capacitor (папка `android`). Собрать APK на своём компьютере можно в Android Studio, а без него — в облаке GitHub:

1. Загрузи проект в репозиторий на GitHub (без `node_modules`).
2. Открой вкладку **Actions** → «Android APK». Сборка запускается сама при каждой загрузке и идёт минут 5–7.
3. В готовом запуске внизу, в разделе **Artifacts**, скачай `smena-na-pvz-apk` — внутри файл `smena-na-pvz.apk`.
4. Скинь его на телефон и открой. Android попросит разрешить установку из неизвестных источников — разреши для приложения, через которое открываешь.

Локально: `npm run build:android` обновляет игру внутри Android-проекта, дальше `cd android && ./gradlew assembleDebug`.
